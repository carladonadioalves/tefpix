# TEFPIX: Your Business Simplified

com esse logo e o roteiro abaixo criar o site:  Roteiro para criação do novo site TEFPIX
1. Objetivo do site

Criar um site institucional moderno para a TEFPIX, apresentando de forma clara os produtos e serviços da empresa, com foco em automação comercial, sistemas de gestão, TEF e tecnologia.

O site deverá ser:

moderno e profissional;
rápido;
totalmente responsivo para celular, tablet e computador;
simples de hospedar;
otimizado para Google;
com predominância de azul, branco e cinza;
com botão flutuante do WhatsApp;
sem chat;
sem excesso de formulários e botões.
2. Tecnologia sugerida

Para esse tipo de site, não será necessário um sistema complexo.

Recomenda-se um site estático utilizando:

HTML5 + CSS3 + JavaScript

Como alternativa, caso seja desejada uma estrutura mais moderna:

Vite + JavaScript + CSS

Não há necessidade de banco de dados, PHP ou WordPress para o site institucional.

Essa abordagem permitirá que o site seja extremamente rápido, seguro e fácil de hospedar em praticamente qualquer servidor.

3. Cabeçalho

No topo do site:

Logo TEFPIX à esquerda.

Menu à direita:

Início | Empresa | Soluções | Serviços | Clientes | Contato

No celular, transformar o menu em ☰.

O cabeçalho pode ficar fixo durante a rolagem.

4. Banner principal

Criar uma área de destaque logo no início da página.

Sugestão de texto

Tecnologia que simplifica o seu negócio

Soluções completas em automação comercial, sistemas de gestão e meios de pagamento para tornar sua empresa mais eficiente.

Utilizar uma imagem relacionada a comércio, tecnologia, automação comercial ou sistemas de gestão.

O principal botão de ação deverá ser:

Falar pelo WhatsApp

Ao clicar, o usuário deverá ser direcionado diretamente para uma conversa com a TEFPIX no WhatsApp.

5. Seção "Nossas Soluções"

Criar cards modernos para apresentar as principais soluções.

Sistema de Gestão

Controle de vendas, estoque, financeiro e operações da empresa em um único sistema.

Automação Comercial

Tecnologia para tornar o atendimento mais rápido, eficiente e integrado.

TEF

Integração de pagamentos diretamente ao sistema de vendas.

PIX integrado

Recebimento de pagamentos via PIX integrado ao sistema.

Cada solução deverá possuir um ícone moderno e uma apresentação visual limpa.

6. Destaque para TEF

Como o TEF é um dos serviços importantes da empresa, deverá existir uma seção exclusiva para apresentar essa solução.

Título

TEF integrado ao seu sistema

Apresentar uma explicação clara sobre a solução, destacando a possibilidade de trabalhar com diferentes adquirentes e bandeiras utilizando o mesmo PIN Pad.

Entre os principais recursos a serem destacados:

Multiadquirente;
Diversas bandeiras;
PIX;
QR Code;
Conciliação;
Integração com ERP.

Visualmente, a seção poderá utilizar uma composição com uma imagem de equipamento de pagamento de um lado e as características da solução do outro.

Ao lado do texto poderá ser utilizada uma imagem relacionada à empresa, tecnologia ou automação comercial.

Direção visual

azul;
branco;
cinza;

tipografia moderna;
ícones minimalistas;
imagens reais de automação comercial, computadores, sistemas e meios de pagamento;
